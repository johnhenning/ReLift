Bars show medians of successful runs; dots show individual trials; whiskers show observed min–max, not confidence intervals. Labels show completed/attempted trials. OOMs are capacity outcomes and have no successful-runtime bar. Measurements are grouped by matching recorded workload and implementation version.

Host RAM is sampled process-tree RSS, not total system memory. GPU memory is sampled total device use, including desktop use. Timed physical disk I/O is distinct from saved dense-output allocation, inventoried when these charts were generated. That allocation excludes shared checkpoints, decoded/provider/mapped caches and cleaned offload scratch. Peak temporary disk space was not recorded. Warm OS caches can make physical reads appear small.
